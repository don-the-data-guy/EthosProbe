# Ethoculus Methodology

Ethoculus investigates observable AI behavior through controlled experiments.

The basic experimental sequence is:

Observation → Replication → Association → Controlled Treatment Effect →
Robust Treatment Effect → Mechanism Hypothesis → Mechanistic Evidence

## Core Rules

1. Define the hypothesis before interpreting the results.
2. Preserve a matched control.
3. Change one material variable where practicable.
4. Repeat trials.
5. Randomize execution order where appropriate.
6. Preserve raw prompts and outputs.
7. Record model and evaluator versions.
8. Retain contradictory evidence.
9. Permit an indeterminate conclusion.
10. Design follow-up experiments intended to falsify important findings.

Behavioral evidence must not be represented as direct access to hidden
weights, hidden activations, private chain-of-thought, consciousness, or intent.

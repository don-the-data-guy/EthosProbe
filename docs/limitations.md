# Limitations

Ethoculus measures observable model behavior.

Unless additional evidence is available, Ethoculus does not claim access to:

- private chain-of-thought;
- hidden model reasoning;
- model consciousness;
- human-like intent;
- hidden weights;
- hidden activations;
- or a complete internal causal mechanism.

A statistically reproducible behavioral relationship is evidence about
behavior under the conditions tested.

It is not automatically proof of why the model behaved that way internally.
